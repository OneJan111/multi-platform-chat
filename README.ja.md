# 🎙️ 配信ダッシュボード

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

配信者と視聴者のための Streamlit ダッシュボードです。**YouTube**、**Bilibili**、**MissEvan（猫耳FM）** のライブチャットを 1 つの画面にまとめ、チャット送信、モデレーション、翻訳、読み上げ、ギフト／スーパーチャットの管理、OBS 操作、分析を提供します。

UI は **English / 简体中文 / 日本語** に対応し、PC とタブレット（横向き・縦向き）の画面に合わせて表示されます。

初めて使う方は [スクリーンショット付き操作ガイド](GUIDE.ja.md) を参照してください。各ページと設定ドロワーを、手順に沿って説明しています。

## TL;DR

**YouTube、Bilibili、MissEvan** の配信状況とチャットを一か所で確認できる多言語ダッシュボードです。チャットの送受信、モデレーション、翻訳、ギフトと収益の集計、読み上げに加え、OBS 操作やチャットオーバーレイにも対応しています。

## 機能

| 機能 | 内容 |
|---|---|
| 💬 **チャット** | YouTube、Bilibili、MissEvan のチャットを 1 つのフィードに表示します。プラットフォームのマークと、各サイト独自のアイコンによるメンバーバッジ（YouTube チャンネルのメンバーバッジ、Bilibili の舰长/提督/总督アイコン、MissEvan の贵族/超粉は 💎）が付きます。各サイトの表示／非表示チェックボックスがあり、サイドバーの単一の文字サイズ設定ですべてのフィードを同時に拡大／縮小できます。メッセージの時刻は既定でサーバーのタイムゾーンを使います。サイドバーの **🕒 チャットのタイムゾーン** で変更できます（URL に `?tz=` として保存されます）。送信欄の横にある **サイト専用スタンプ** ピッカーには、YouTube チャンネルスタンプ、Bilibili ルームスタンプ、MissEvan のルームスタンプと内蔵顔文字プリセットがあります。YouTube スタンプはチャットから収集され、ログインすると全セットを表示し、使用できないものには 🔒 を付けます。Bilibili スタンプにはログインが必要で、🔒 はファンメダルなどが必要な場合があります。配信者の **充电表情** はログインなしでも一覧に表示され、配信者に充電すると使えます。Bilibili と MissEvan のピッカーは該当ルームのリスナーを起動中のみ利用できます。YouTube スタンプと MissEvan の顔文字はメッセージ欄に追加され、**送信** を押すと投稿されます。Bilibili の専用スタンプはクリックすると単独のコメントとしてすぐ送信されます。YouTube／Bilibili の専用スタンプはそれぞれのサイトにだけ送信され、通常の絵文字はテキストのコメントに複数組み合わせられます。MissEvan のルームスタンプもクリックするとすぐ送信されます。スタンプパックは現在の YouTube 配信 / Bilibili ルームごとにキャッシュされ、配信やルームを切り替えると再取得します。各パックは折りたためます（**すべて展開 / すべて折りたたむ** も使えます）。配信者自身の Bilibili パック（⭐：充电表情、房间专属表情、配信者自身の装扮パック）が先頭に並び、最初から開いています。装扮パックには装扮の名前が付き、装扮ショップに持ち主の UP主 が載っていればその名前も付きます。入力した YouTube のコード（`:_wave:` など）は YouTube ではスタンプになり、Bilibili／MissEvan に送る文からは除かれます。 |
| 🐱 **MissEvan ルームスタンプ** | ログイン後、選択したルームで使えるパッケージをピッカーに表示します。パッケージを開いてスタンプをクリックすると MissEvan に送信します。ロック中のパッケージは送信できません。受信したルームスタンプは、信頼できる MissEvan CDN の画像に限りチャットと OBS ブラウザーオーバーレイに表示します。 |
| ✉️ **送信** | 1 つのメッセージを複数のサイトに同時に投稿します（YouTube / Bilibili / MissEvan にチェック）。 |
| 🎁 **ギフトとスーパーチャット** | ギフト（無料ギフトを含む）、スーパーチャット、スーパーステッカー、メンバーシップ、有料質問は専用の列に表示されます。価格が取得できたギフトは各項目に金額を表示し、見出しには通貨ごとの受取合計を表示します（通貨間の換算や合算はしません）。YouTube のメンバーシップギフトは、贈った人の購入（「10 件のメンバーシップをギフト」）と各受取人（「… からメンバーシップギフトを受け取りました」）を表示します。Bilibili の 🧧 红包 は送り主、金額、中身を表示し、抽選が終わると当選者を表示します。受取人と当選者は一覧に表示されますが、読み上げはしません。各項目を 🙏 *お礼済み*（グレー表示）にするか、*すべてお礼済みにする* を使います。 |
| 👋 **入室** | 広い画面ではギフトの下に専用フィードを表示します。狭い画面ではチャット内に最新の入室者だけを1行で表示し、ほかの入室リストや操作を隠します。 |
| 🛡️ **モデレーション** | メッセージの 🚫 でそのユーザーをブロックします。ブロックしたユーザー、キーワード・正規表現フィルター、許可リストは `chat_filters.json` に保存され、再起動後も保持されます。 |
| 🌐 **翻訳** | サイドバーで翻訳を開始すると、チャットとライブ文字起こしのうち、選択した翻訳先と異なる言語の内容を翻訳します。中国語（簡体字/繁体字）、英語、日本語、韓国語に対応します。`.env` で Index-Translate、LM Studio などのローカル／ホスト型 OpenAI 互換 API、Google を選択できます。Index-Translate は失敗時に Google にフォールバックし、互換 API モードでは設定した API のみを使用します。配信用語は内蔵用語集で機械翻訳を上書きします。 |
| 🎙️ **ライブ文字起こし** | 受信中の YouTube、Bilibili、MissEvan の配信から一度に 1 つを選び、音声を文字起こしします。実行中は最新 3 件の文字起こしをチャットとギフト両列の上に全幅で固定表示します。音声認識にはローカルの faster-whisper を使い、選択したモデルは初回使用時にダウンロードされます。FFmpeg が必要です。翻訳を開始していて、検出言語が選択した翻訳先と異なる場合に文字起こしを翻訳します。 |
| 🔤 **読み仮名** | スーパーチャットの文字、ギフト名、ユーザー名にピンイン／振り仮名のルビを付け、配信者が読み上げやすくします。日本語の翻訳には振り仮名、スーパーチャットとギフトの中国語の翻訳にはピンインを付けます。 |
| 💾 **設定の保存** | 設定（読み上げ、翻訳、メッセージ順序、文字サイズ、OBS オーバーレイのオプション、言語、タイムゾーンなど）はこのブラウザに保存され、次回開いたときに復元されます。フィードのレイアウトは画面幅に合わせて自動で切り替わります。ルームID、配信URL、チャットは保存されません。ログインは別の Cookie を使います。 |
| 🔊 **読み上げ** | このパソコンでチャットを読み上げる（オフラインの `pyttsx3` またはオンラインの gTTS）か、**視聴者のブラウザで端末の音声を使って読み上げます**（別の端末や Streamlit Cloud からダッシュボードを開いたときは自動的にこちら）。言語フィルター、絵文字のスキップ、翻訳文の読み上げ（読み上げ言語が自動検出、または *翻訳先* と同じとき）、通常のチャットでユーザー名を読まない設定、**ギフトとスーパーチャットの優先読み上げ**、各メッセージの 🔊 再生ボタン、センシティブなコメントをすぐに止める **⏭ スキップ / ⏹ 読み上げ停止** ボタンを備えています。 |
| 📡 **配信モニタリング** | サイトごとの操作（配信 URL / ルーム ID、受信の開始・停止、ログイン状態）と、各プラットフォームの配信中 / オフライン状態、タイトル、視聴者数。 |
| 🎬 **OBS** | 配信者向けの OBS 専用タブです。接続、配信・録画の開始/停止、シーンとソースの切り替え（OBS WebSocket v5）、OBS テキストソースへのチャット送信、チャット専用のブラウザソース用オーバーレイ。このタブで *OBS に接続* をオンにするまでは何もしません。 |
| 📊 **分析** | 視聴者数（配信モニタリングから取得）、1 分あたりのメッセージ数、よく発言する視聴者、サイト別のギフト／スーパーチャット数と収益（サイトごとの通貨で集計）、切り抜き用の 🔥 ホットスポット（CSV、タイムスタンプ一覧、DaVinci Resolve の EDL マーカー）。 |
| 🍪 **Cookie** | Bilibili、MissEvan、YouTube のログイン Cookie を取り込みます。このパソコンのブラウザ（Chrome / Edge / Firefox）から読み取るか、任意のブラウザから書き出した Cookie を貼り付け／アップロードします（サーバー向け）。 |

## 動作環境

- Python 3.10 以上（3.14 で開発）
- Windows、macOS、Linux（オフライン読み上げの音声は OS に依存）
- ライブ文字起こし（任意）：FFmpeg をインストールして `PATH` に追加してください。faster-whisper と yt-dlp は依存関係と一緒にインストールされ、Whisper モデルは初回使用時にダウンロードされます。
- 任意：WebSocket サーバーを有効にした [OBS Studio](https://obsproject.com/) 28 以上

## インストール

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## 設定

設定はプロジェクト直下の `.env` ファイルから読み込みます（`python-dotenv` を使用）。まずテンプレートをコピーします：`Copy-Item env.template .env`（macOS/Linux：`cp env.template .env`）。すべて任意なので、使うプラットフォームの分だけ記入してください。サイトのログインは `.env` では **設定しません**。各自が 🍪 Cookie タブで自分の Cookie を取り込みます（[チャットを送信するためのログイン](#チャットを送信するためのログイン) を参照）。

テンプレートにはプレースホルダー（`your-…`、`xxx`）しか入っていません。**書き換えるか、その行を削除してください。** プレースホルダーは実際の設定として扱われます（たとえばプレースホルダーの `OBS_PASSWORD` があると、その値で OBS にログインしようとします）。

| 変数 | 用途 | 既定値 |
|---|---|---|
| `YOUTUBE_API_KEY` | YouTube Data API キー（任意）。ない場合（またはクォータ切れの場合）、チャットと配信状態の取得は公開ウェブページを使います | — |
| `YOUTUBE_CHANNEL` | 配信モニタリングタブの既定の YouTube チャンネルリンク（または配信 URL）。*受信を開始* で監視します | `https://www.youtube.com/@Ya-chan` |
| `BILIBILI_ROOM_ID` | 既定の Bilibili ライブルーム | — |
| `MISSEVAN_ROOM_ID` | 既定の MissEvan ライブルーム | `869215180` |
| `INDEX_TRANSLATE_API_BASE` | Index-Translate API のベース URL。空にすると無効になり Google を直接使用 | `https://index-translate.bilibili.com/v1` |
| `INDEX_TRANSLATE_MODEL` | Index-Translate モデル | `Index-Translate-35B-A3B` |
| `TRANSLATION_PROVIDER` | 翻訳プロバイダー：`index`、`openai_compatible`、`google` | `index` |
| `OPENAI_COMPATIBLE_TRANSLATE_API_BASE` | OpenAI 互換 API のベース URL（`/v1` を含む。LM Studio の例：`http://localhost:1234/v1`） | `http://localhost:1234/v1` |
| `OPENAI_COMPATIBLE_TRANSLATE_MODEL` | API が受け付ける正確なモデル ID | `local-model` |
| `OPENAI_COMPATIBLE_TRANSLATE_API_KEY` | API キー。ローカルサーバーでは不要な場合があり、ホスト型 API では通常必要 | — |
| `OBS_HOST` | OBS WebSocket のホスト | `localhost` |
| `OBS_PORT` | OBS WebSocket のポート | `4455` |
| `OBS_PASSWORD` | OBS WebSocket のパスワード | — |
| `OVERLAY_HOST` | チャットオーバーレイの待ち受けアドレス：`127.0.0.1` = このパソコンのみ、`0.0.0.0` = 他のマシンからも接続可 | `127.0.0.1` |
| `OVERLAY_PORT` | チャットオーバーレイのポート | `8502` |
| `OVERLAY_PUBLIC_URL` | 🎬 OBS タブに表示するオーバーレイのアドレス（例：`http://203.0.113.5:8502` やリバースプロキシの URL） | 自動 |
| `ANALYTICS_ENABLED` | `false` にすると両アプリの分析ページ/タブを非表示にし、視聴者数の履歴、アクティビティ、ホットスポットデータの収集を停止します | `false` |
| `MEMORY_TRACE_ENABLED` | デスクトップの Python メモリ割り当て追跡。10 秒ごとに追跡サイズ、60 秒ごとに増加の大きいソース位置を記録します。CPU・RAM の負荷が増えます。変更後は再起動し、診断後は無効にしてください。 | `false` |
| `TTS_USE_GTTS` | `true` = オンラインの gTTS、`false` = オフラインの pyttsx3 | `false` |
| `TTS_QUEUE_LIMIT` | オフラインの通常チャット・入室通知の待機上限。満杯時は最も古いメッセージを破棄 | `20` |
| `TTS_PRIORITY_QUEUE_LIMIT` | オフラインのギフト・Super Chat の待機上限。満杯時は最も古い優先メッセージを破棄 | `50` |
| `TTS_TASK_LIMIT` | デスクトップの実行中・待機中の音声生成タスク上限。満杯時は新しい読み上げをスキップ | `20` |
| `TTS_AUDIO_QUEUE_LIMIT` | デスクトップのオンライン音声の再生待ち上限。満杯時は最も古い待機音声を破棄 | `20` |
| `SIMPLE_CHAT_POLL_INTERVAL` | `simple_app.py` と `simple_server_app.py` のチャット取得・フィード更新間隔（秒）。最小 `1`。YouTube の通信は Bilibili / MissEvan の配信を妨げません。簡易サーバーは WebSocket キューを独立して読み取り、開始時刻間の間隔でポーリングします。サーバー取得とブラウザー更新は別タイマーのため、表示遅延には両方の間隔とプラットフォームの遅延が含まれる場合があります。 | `15` |
| `SIMPLE_STATUS_POLL_INTERVAL` | 簡易モニターの配信状態・チャンネル確認間隔（秒）。最小 `1` | `60` |
| `CHAT_POLL_INTERVAL` | チャットの更新間隔（秒）。デスクトップ版の Bilibili / MissEvan WebSocket メッセージは、ルーム状態と YouTube API リクエストとは独立して配信されます。変更後は再起動が必要です。 | `5` |
| `ROOM_STATUS_POLL_INTERVAL` | デスクトップ版の状態確認とブラウザー版の状態データのキャッシュ間隔（秒）。YouTube チャンネル監視にも適用。最小 `1`。変更後は再起動が必要です。メイン画面の状態・文字起こしパネルはバックグラウンド更新せず、アプリの再実行時に更新されます。ライブ通知もバックグラウンドでは確認されません。 | `60` |
| `CHAT_TRANSLATION_DISPLAY_MODE` | `immediate` = チャットをすぐ表示し、翻訳完了後に訳文を追加；`wait` = 翻訳完了後にメッセージを表示 | `immediate` |
| `LOGIN_SECRET` | 各ユーザーのブラウザに保存されるログイン情報を暗号化するキー。変更すると全員がログアウトされます | ランダム、`.login_secret` に保存 |

> ⚠️ `.env` と `.login_secret` には秘密情報が含まれ、`.gitignore` に登録されています。コミットや共有は絶対にしないでください。

## 起動

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

<http://localhost:8501> を開きます。同じネットワークのタブレットから使う場合は `http://<PCのIP>:8501` を開きます。

簡易モニターを使うには、次を実行します。.env に設定したプラットフォームだけを自動で監視し、配信状態、チャット、ギフトを表示します。

```powershell
.\.venv\Scripts\python.exe -m streamlit run simple_app.py
```

翻訳とブラウザーの音声読み上げ設定はサイドバーにあります。
チャットとギフトには、利用可能な場合にユーザーのアバターを表示し、取得できない場合は名前の頭文字を表示します。
設定したすべてのチャンネルがオフラインの間は状態確認を続け、いずれかが配信中になると停止します。チャットとギフトの更新は続きます。状態確認を再開するにはモニターを再起動してください。

Streamlit サーバーが動作している間、チャットとギフトの履歴をメモリに保持するには、次を実行します。

```powershell
.\.venv\Scripts\python.exe -m streamlit run simple_server_app.py
```

一度アプリを開くと、すべてのブラウザーセッションが切断された後もバックグラウンドで監視を続けます。いずれかの設定済みチャンネルが配信中になると状態確認を停止しますが、その配信のチャット取得は続きます。状態確認を再開するにはサーバーを再起動してください。履歴は同じサーバーに接続しているブラウザーセッション間で共有され、サーバー停止時に消去されます。

新しいセッションの既定値は `.env` で設定できます（`env.template` を参照）。

| 設定 | 既定値 | 用途 |
|------|--------|------|
| `SIMPLE_PAGE_LANGUAGE` | `ja` | UI と翻訳の言語：`en`、`zh`、`ja` |
| `SIMPLE_TRANSLATION_ENABLED` | `true` | チャット翻訳を有効化 |
| `SIMPLE_TTS_TRANSLATE` | `true` | TTS 有効時に翻訳済みチャットを読み上げ |
| `SIMPLE_NOTIFY_LIVE` | `true` | 配信開始通知を有効化（ブラウザーの許可が必要） |
| `SIMPLE_OVERLAY_COUNT` | `10` | 簡易モニターの OBS リンクで表示するチャット・ギフトの合計上限（1–50） |

Streamlit Community Cloud（`*.streamlit.app`）では、ポート 8502 ではなく同じ HTTPS アドレスの `?view=overlay` を使用します。更新後はサイドバーの新しい URL を OBS にコピーしてください。`OVERLAY_PUBLIC_URL` を指定した場合はそちらを優先します。背景が透明でない場合は OBS のカスタム CSS に `body, .stApp { background: transparent !important; }` を設定してください。

両方の簡易モニターのサイドバーに OBS 用スタンドアロンオーバーレイを追加しました。サイトを選択し、チャット・Super Chat・ギフトをまとめた All リンクだけを表示します。OBS のブラウザーソースに貼り付けてください。サーバーが起動中ならページを閉じても動作し、アバター（取得できない場合は頭文字）も表示します。`.env` の `SIMPLE_OVERLAY_COUNT` を変更したら再起動し、更新されたリンクを OBS にコピーしてください。別の PC の OBS から使う場合は `OVERLAY_HOST` / `OVERLAY_PUBLIC_URL` を接続可能な値に設定してください。

変更後は再起動してください。既存のセッションではサイドバーの選択を保持します。TTS 自体は既定でオフです。

Windows ではセットアップ後に [Start_Simple_Monitor.bat](Start_Simple_Monitor.bat) をダブルクリックして起動できます。
プロジェクトの `.venv` があれば優先し、なければ `PATH` の Python を使用してブラウザーを開きます。
既定のポートは 8501 です。環境変数 `SIMPLE_MONITOR_PORT` で変更できます。

## 使い方

### チャットを読む（ログイン不要）

ルームを受信中は、配信モニタリング画面の上部に **💬 チャット** への切り替え案内を表示します。すべての受信を停止すると案内は非表示になります。

**📡 配信モニタリング** タブにはサイトごとに列があり、どの列も同じ構成です：

1. **🔑 ログイン**：ログイン中のアカウント（5 分ごとに再確認）、*ログインの期限切れ*、または *未ログイン — チャットは閲覧のみ*。
2. **ルームIDまたはURL**：読み取る配信。
3. **🎧 受信**：*受信中 ✓* / *接続中…* / *受信していません*、および **▶ 受信を開始** と **⏹ 受信を停止**。ルームを変更すると現在の受信は停止します。
4. 配信中 / オフライン状態、タイトル、視聴者数。

**ルームIDまたはURL** に入力するもの：

- **YouTube**：配信 URL または動画 ID。**チャンネルリンク**（例：`https://www.youtube.com/@Ya-chan`）も使えます。60 秒ごとにチャンネルを確認し、配信が始まるとすぐにチャットを読み始め、配信終了後は監視に戻ります。
- **Bilibili**：ルーム ID または URL（例：`https://live.bilibili.com/21452505`、または `b23.tv` の共有リンク）。ログイン Cookie がないと、Bilibili はユーザー名を伏せ字にします（例：波***）。
- **MissEvan**：ルーム ID または URL（例：`https://fm.missevan.com/live/869215180`）。

### チャットを送信するためのログイン

1. 普段使っているブラウザでそのサイトにログインします。
2. **🍪 Cookie** タブでブラウザとサイトを選び、Cookie を取り込んで **✅ この Cookie を使用** をクリックします。
   - **アプリがサーバーや別のパソコンで動いている場合：** アプリは自分が動いているマシンにインストールされたブラウザしか読めません（それ以外では `Could not find Firefox profile directory` になります）。そのため **🧭 このパソコンのブラウザ** は、そのマシン上でダッシュボードを開いたときだけ表示されます。代わりに **📋 Cookie を貼り付け / アップロード** を選び、自分のブラウザから書き出した Cookie を貼り付けてください。開発者ツールからコピーした `Cookie:` ヘッダー（F12 → Network）や、*Get cookies.txt LOCALLY*（Netscape `cookies.txt`）、*Cookie-Editor*（JSON）などの拡張機能で書き出したものが使えます。書き出したファイルをアップロードすることもできます。
3. メッセージ欄の上の **送信先** でサイトにチェックを入れて送信します。

MissEvan への送信には取り込んだアカウントを使います。ルームで発言できるアカウントが必要で、サイトのウェブ版では電話番号の紐付けが必要です。紐付け後も送信できない場合は、MissEvan の Cookie を再取り込みしてください。

**ログインはユーザーごとです。** ダッシュボードを開いた人はそれぞれ自分のログインを持ちます。あなたの Cookie が他の人に使われたり表示されたりすることはなく、他の人があなたとしてチャットを送ることもできません。ログイン情報は暗号化された Cookie としてあなたのブラウザにだけ保存され（サーバーが持つのはキー `LOGIN_SECRET` / `.login_secret` だけです）、ページの再読み込みやサーバーの再起動後も保持されます。別のブラウザやプライベートウィンドウで開くとログアウト状態になります。開始した受信は、開始時のログインを使います。

各 **📡 配信モニタリング** 列の 🔑 行にログイン状態が表示されます。MissEvan の Cookie が期限切れになると MissEvan への送信は無効になります。その下の **🚪 ログインを解除** をクリックすると、そのサイトの Cookie を忘れます。このセッションとこのブラウザから削除され、チャットは読み取り専用で引き続き使えます。

Google アカウントで複数の YouTube チャンネル（ブランドアカウント）を持っている場合、YouTube のログイン行の下に **送信するチャンネル** の選択欄が表示されます。チャットを送るチャンネルを選んでください。選択はユーザーごとで、ログインと一緒に保存されます。別の Google アカウントを使うには、🍪 Cookie タブでそのアカウントの Cookie を取り込みます。

ブラウザの Cookie で YouTube に送信するのは非公式な方法（youtube.com 自体と同じ仕組み）で、チャットが有効な配信でのみ使えます。

### チャットの表示

チャット原文は翻訳を待たずに表示し、翻訳が完了すると次の更新で追加します。翻訳読み上げも完了まで保留し、新しいチャットを遅らせません。リストをミュートするか読み上げを停止すると、保留中の自動読み上げを取り消します。

実験的なライブ文字起こしは既定で非表示です。`.env` に `TRANSCRIPTION_ENABLED=true` を設定して再起動すると、文字起こしの入口とライブプレビューが表示されます。`false` で再び非表示にできます。チャット翻訳には影響しません。

チャットは選択した表示順の先頭または末尾にある最新メッセージへ自動追従します。履歴へスクロールすると追従を一時停止し、最新位置に戻るか矢印ボタンを押すと再開します。

- **グローバル設定** サイドバーの **チャット文字サイズ** スライダーで、チャット・ギフト・入室の文字を一括で変更できます（80–200%）。
- サイドバーで **新しい順（上）** または **新しい順（下）** を選ぶと、ライブ文字起こし・チャット・ギフトの表示順をまとめて変更できます。
- 広い画面では左側にライブ文字起こしとチャット、右側にギフトとスーパーチャットを表示します。狭い画面ではギフトとスーパーチャットをライブ文字起こしとチャットの間に移動し、見出しから領域全体を折りたためます。
- チャットをスクロールしてもライブ文字起こしのプレビューは上部に固定されます。通常のチャットでは時刻を表示し、メンバーの文字ラベルを隠して、ユーザー名を控えめにし本文を目立たせます。
- 狭い画面では専用の入室フィードと操作を隠し、最新の入室者だけをチャット内に1行で表示します。
- フィードの上の YouTube / Bilibili / MissEvan のチェックボックスで、各サイトのメッセージを表示／非表示にします。
- チャット／ギフトフィード、生成音声プレーヤー、OBS 操作欄は `CHAT_POLL_INTERVAL` 秒ごと（既定 5 秒）に別々に更新されます。メインブラウザー版の gTTS 音声生成、OBS テキスト送信、OBS 操作、状態取得は独立したバックグラウンド処理で、チャットを妨げません。停止後に届く音声は破棄します。オフライン音声と文字起こし認識は専用ワーカーを維持します。配信状態と文字起こし表示は操作時または通常の再実行時に更新されます。簡易アプリはブラウザー音声を使い、OBS 操作、文字起こし、ディスクへのチャット保存は提供しません。簡易サーバーの履歴はメモリー内のみです。
- サイドバーの *🗑️ チャット履歴を消去* はチャットと入室を空にしますが、ギフトとスーパーチャットは残すので、まだお礼をしていない人を見失いません。

サイドバーで翻訳先を選択して **翻訳を開始** をオンにすると、チャットと文字起こしのうち選択した翻訳先と異なる言語の内容を翻訳します。既定では Index-Translate を優先し、利用できない場合は Google にフォールバックします。LM Studio やホスト型モデル API を使うには `.env` で `TRANSLATION_PROVIDER=openai_compatible` を設定し、`OPENAI_COMPATIBLE_TRANSLATE_API_BASE`、`OPENAI_COMPATIBLE_TRANSLATE_MODEL`、必要に応じて `OPENAI_COMPATIBLE_TRANSLATE_API_KEY` を指定してください。ホスト型 API の場合、テキストは設定したサービスだけに送信され、別のクラウドサービスへはフォールバックしません。既存の `LM_STUDIO_TRANSLATE_*` 設定も、汎用設定が未指定の場合は引き続き使用できます。配信用語は内蔵用語集で機械翻訳を上書きします。

### ギフトとスーパーチャット

- 新しいギフトとスーパーチャットは右側の列に表示されます。視聴者にお礼を言ったら項目をクリックすると、グレーになり ✅ *お礼済み* の印が付きます。もう一度クリックすると元に戻ります。
- *🙏 すべてお礼済みにする* で、現在未対応の項目をすべてお礼済みにします。
- 価格を取得できたギフトは各項目に金額を表示し、見出しには通貨別の受取合計を表示します。通貨は換算・合算しません。
- お礼済みの状態は現在のブラウザセッションの間だけ保持されます。

### ユーザーのブロック

Deploy と同じ上部バーのアイコンと文字の入口から画面を切り替えます。狭い画面では入口を横スクロールできます。最初は配信モニタリングが表示され、文字起こしは有効時だけ表示されます。設定は通常非表示の ☰ ドロワーに残り、ページ幅を変えずに手前に重なります。Escape キーでも閉じられます。

- メッセージの 🚫 をクリックすると投稿者をブロックします。その人のメッセージはダッシュボードから消え、以後もフィルターされます。YouTube / Bilibili / MissEvan には何も送信されません。
- ブロックはプラットフォームごとで、`chat_filters.json`（git 管理外）に保存され、再起動後も保持されます。サイドバーから **🛡️ フィルター** を選択し、✕ で解除します。
- **🛡️ フィルター** 画面では、ブロックするキーワード、正規表現、ユーザー名 / ID を手動で追加することもできます。

### 読み上げ

読み上げが有効な間、詳細モードなしでチャット上部のオプションを使えます。**絵文字** は絵文字やスタンプを省略し、**ユーザー名** はチャットのユーザー名を省略し、**翻訳** は翻訳したチャットを読み上げます。有効なボタンは強調表示され、再度押すと無効になります。

各リストはスピーカーアイコンだけのボタンでミュートを切り替え、ツールチップで操作を説明します。絵文字とユーザー名のミュートボタンも、有効時は消音、無効時は音声ありのスピーカーを表示します。

ギフトとスーパーチャットの翻訳読み上げも **翻訳** ボタンで切り替えます。両方の翻訳ボタンは有効時に緑色、無効時に緑の枠線で表示されます。

サイドバーの **🔊 読み上げ** で設定します：*読み上げを有効化*、*言語*、*速度（WPM）*、*音量*。*▶ 音声テスト* で確認できます。読み上げが有効な間、各リスト（ギフトとスーパーチャット、チャット、入室）の上に **🔊 読み上げ / 🔇 読み上げない** ボタンが表示され、そのリストを読み上げるかを切り替えられます。チャットリストの上には *絵文字を無視*、*ユーザー名を読み上げない*（ギフトとスーパーチャットは送り主を読み上げます）、*翻訳したチャットを読み上げ* もあります。ギフトとスーパーチャットのリストの上には *翻訳したスーパーチャットを読み上げ* があります（ギフト名は常にそのまま読み上げます）。初期設定ではギフトとスーパーチャット、チャットを読み上げ、入室は読み上げません。ギフトとスーパーチャットは言語に関係なく優先して読み上げ、入室は更新ごとに最新の数件だけを読み上げます。

センシティブなコメントを止めるには、**各フィードの上の右側** のボタン（読み上げがオンのときに表示）を使います。**⏭ スキップ** は現在のメッセージを止めて次へ進み、**⏹ 読み上げ停止** は止めたうえで待機中のメッセージもすべて破棄します。その後に届いたチャットは引き続き読み上げられます。完全に止めるには *読み上げを有効化* をオフにしてください。

エンジン（オフラインの pyttsx3 かオンラインの gTTS）は `.env` の `TTS_USE_GTTS` で選びます。

**読み上げ先 → このブラウザ（端末の音声）** はブラウザの Web Speech API を使うので、スピーカーのない Streamlit Cloud やリモートサーバーでも使えます。リモートの視聴者は常にブラウザの音声を使います。ページは開いたままにしておく必要があり、ブラウザはページを一度クリックするまで音を出しません。

### OBS

OBS で **ツール → WebSocket サーバー設定** を開き、サーバーを有効にして `.env` と同じポート/パスワードを設定します。次に **🎬 OBS** タブを開き、**OBS に接続** をオンにします（既定はオフで、オフの間ダッシュボードは OBS に一切接続しません）。OBS の機能はすべてこのタブにあります。OBS に接続すると配信・録画の操作、シーン、ソースが表示されます。OBS が起動していなければ未接続と表示され、15 秒ごとに再確認します。

OBS にチャットを表示するには、**テキスト (GDI+)** ソース（または FreeType テキストソース）を追加し、🎬 OBS タブで **チャットを OBS テキストソースに送信** をオンにしてそのソースを選びます。このソースには最新 10 件の通常チャットが古い順に、ユーザー名やバッジなしで表示されます。**翻訳を開始** がオンのときは、翻訳がある場合に原文の下に表示されます。オフにすると次の更新で翻訳が消えます。OBS へのチャット出力はオプトインで、設定した WebSocket サーバーを使います。別のブラウザソース用オーバーレイのプレビューはこのテキストソースを更新しません。

または、`http://localhost:8502/overlay`（`:8501/overlay` ではありません）を指す OBS の **ブラウザソース** を追加します。このページは、スーパーチャット、ギフト、メンバーシップ（Bilibili の SC とギフト、MissEvan の有料質問とギフト、YouTube のスーパーチャット/スーパーステッカーとメンバーシップ）をオーバーレイの上部に固定し、通常のチャットを下部に表示するので、チャットが多くても有料イベントが押し流されません（既定 3 件。**OBS オーバーレイに表示するスーパーチャット・ギフト数** を 0 にすると非表示）。通常のチャットは最新のもの（既定 5 件。🎬 OBS タブの **OBS オーバーレイに表示するメッセージ数** で 1–50 に変更）を表示し、**翻訳を開始** がオンのときだけ翻訳を表示します。任意のカスタムオーバーレイメッセージも表示できます。🎬 OBS タブで **OBS オーバーレイにユーザー名を表示** をオフにすると、ユーザー名なしでチャットの文だけを表示します（既定はオン）。プレビューも同じ設定に従います。Bilibili のカスタム絵文字（例：`[doge]`）、スタンプ弾幕、YouTube チャンネルのカスタム絵文字（`:_wave:` などのメンバースタンプ）、スーパーステッカーの画像は、ダッシュボード、プレビュー、ブラウザソースで画像として表示されます。OBS テキストソースではテキストのコードしか表示できません。更新を受け取るにはダッシュボードを開いたままにしてください。ポート 8502（`OVERLAY_PORT`）が空いている必要があり、オーバーレイサーバーを起動できない場合は 🎬 OBS タブにエラーが表示されます。ブラウザソースは *OBS に接続* がオフでも使えます。オーバーレイは既定で `127.0.0.1` だけで待ち受けます。ダッシュボードをサーバーで動かす場合は `OVERLAY_HOST=0.0.0.0` を設定し（ファイアウォールでポートも開放）、PC の OBS から `http://<サーバー>:8502/overlay` を読み込めるようにします。正確な URL は 🎬 OBS タブに表示されます。オーバーレイは読み取り専用で、公開チャットだけを表示します。複数の人が同じダッシュボードを使う場合は、🎬 OBS タブでそれぞれに別の **オーバーレイチャンネル** を設定してください（オーバーレイ URL に `?ch=名前` が付きます）。そうしないと、開いているすべてのダッシュボードが同じオーバーレイに出力し、最後のものが優先されます。

オーバーレイに一部のサイトだけを表示するには、🎬 OBS タブの **このオーバーレイに表示するサイト** で選ぶか、URL に `site=` を自分で付けます：`/overlay?site=youtube`、`/overlay?site=bilibili,missevan`、`/overlay?ch=alice&site=bili`（短縮名 `yt`、`bili`、`me` も使えます）。URL ごとにメッセージ数が個別に適用されるので、サイトごとにブラウザソースを追加できます（例：片側に YouTube のチャット、もう片側に Bilibili）。`site=` がなければすべてのサイトを表示します。

オーバーレイ（スーパーチャット・ギフト・チャットとその翻訳）の漢字の上に**ピンイン／振り仮名**を表示するには、🎬 OBS タブの **OBS オーバーレイの読み仮名（ピンイン／振り仮名）** で *自動*・*ピンイン*・*振り仮名* を選びます。単独のリンクでは `ruby=auto`、`ruby=pinyin`、`ruby=furigana` を付けます。視聴者にも見え、各行が高くなるため、既定ではオフです。
スーパーチャットとチャットを**別の画面やシーン**に表示するには、🎬 OBS タブ上部の *スーパーチャットとギフトのみ*（`n=0`）と *チャットのみ*（`sc=0`）のリンクで、ブラウザソースを 1 つずつ追加します。片方を 0 にすると、もう片方がブラウザソースの高さ全体を使います。

**Streamlit Community Cloud / ホスティングされたダッシュボード：** ダッシュボードのポートしか公開されないため、`:8502/overlay` にはアクセスできません。その場合、🎬 OBS タブには代わりにダッシュボードのリンクが表示されます。例：`https://your-app.streamlit.app/?view=overlay&youtube=@channel&n=10&sc=5`。このページはオーバーレイだけを表示し、2 秒ごとに更新されます。OBS で背景が透明にならない場合は、ブラウザソースの *カスタム CSS* に `body, .stApp { background: transparent !important; }` を追加してください。

### 🔥 切り抜き用ホットスポット

📊 分析タブでは、チャット、ギフト、スーパーチャットがその配信の普段の水準を大きく上回った瞬間を見つけます（スコア = 集計間隔ごとのメッセージ数 + 5 × ギフト/SC 数、中央値と比較）。各ホットスポットには、配信開始からの開始/終了時刻（配信モニタリングから自動取得するか、最初のメッセージ、または入力した時刻を基準）、ピーク、よく出た言葉が表示されます。チャットは出来事の後に反応するため、*前余白*（既定 20 秒）の分だけクリップの開始を早めます。ダウンロード形式：

- **CSV**（Excel で開けます）：時刻、件数、言葉；
- **タイムスタンプ（.txt）**：`HH:MM:SS` の行。動画の概要欄やメモにそのまま貼り付けられます；
- **DaVinci Resolve 用マーカー（.edl）**：録画をタイムラインに置き、メディアプールでそのタイムラインを右クリック > *タイムライン > 読み込み > EDL からタイムラインマーカーを読み込み*。*EDL タイムライン開始* はタイムラインの開始と同じにしてください（既定は Resolve と同じ `01:00:00:00`）。

ダッシュボードのページを開いている間に受信したメッセージだけが集計されます。

  browser_cookies.py   インストール済みブラウザや貼り付け/書き出したテキストから Cookie を取り込み
  user_login.py        ユーザーごとのログイン（セッション + 暗号化されたブラウザ Cookie）
  filters.py           キーワード / 正規表現 / ユーザーのフィルター（chat_filters.json に保存）
  translate.py         バックグラウンドでキャッシュ付きのチャット翻訳
  reading.py           ピンイン / 振り仮名の読み仮名
  tts.py               優先度付きキューによる読み上げ

## トラブルシューティング

| 問題 | 対処 |
|---|---|
| OBS が「未接続」と表示される | 警告に原因が表示されます。*応答なし*：OBS が起動していないか WebSocket サーバーがオフです。OBS を起動するかサーバーを有効にし、`OBS_HOST` / `OBS_PORT` を確認してください。*ログイン拒否*：`OBS_PASSWORD` が間違っています。OBS を使わない場合は *OBS に接続* をオフにしてください。 |
| ダッシュボードをサーバーで動かすと OBS に接続できない | `OBS_HOST=localhost` はサーバー自身を指します。`OBS_HOST` を OBS が動いている PC の IP にし、サーバーからその PC に届くようにして（同じ LAN、Tailscale などの VPN、ポート転送）、その PC のファイアウォールでポート 4455 を許可してください。チャットオーバーレイ（`:8502`）は、`OVERLAY_HOST=0.0.0.0` を設定してサーバーのファイアウォールでポートを許可しない限り `127.0.0.1` だけで待ち受けます。 |
| `bilibili-api-python not installed or connection failed` | 仮想環境内で `pip install -r requirements.txt` を実行し、ルーム ID とネットワークを確認してください。 |
| YouTube 送信：「Chat is disabled」 | その配信はチャットがオフか、配信中ではありません。 |
| オフラインで一部の言語が読み上げられない | オフライン読み上げは Windows にインストールされた音声を使います。*設定 → 時刻と言語 → 音声認識* で中国語 / 日本語の音声があるか確認するか、`TTS_USE_GTTS=true` にしてください。 |
| オフラインで韓国語の音声がない | Windows に韓国語の音声をインストールするか（設定 → 時刻と言語 → 音声認識）、`TTS_USE_GTTS=true` にしてください。 |
| 読み上げの音が出ない | *読み上げを有効化*、音量、メッセージの言語が読み上げの *言語* と一致しているか（または *自動検出* を使う）を確認してください。 |
