# 🎙️ 直播仪表板

[English](README.md) | **简体中文** | [日本語](README.ja.md)

一个面向主播和观众的 Streamlit 仪表板。它把 **YouTube**、**B站（Bilibili）** 和 **猫耳FM（MissEvan）** 的直播弹幕合并到一个画面，并提供发送弹幕、管理、翻译、语音朗读、礼物/醒目留言记录、OBS 控制和数据分析等功能。

界面支持 **English / 简体中文 / 日本語**，适配电脑和平板（横屏、竖屏均可）。

## TL;DR

一个多语言直播仪表板，集中查看 **YouTube、B站和猫耳FM** 的直播状态与弹幕。支持收发弹幕、管理和翻译消息、统计礼物与收益、语音朗读，以及 OBS 控制和弹幕叠加层。

## 功能

| 功能 | 说明 |
|---|---|
| 💬 **弹幕** | YouTube、B站和猫耳FM 的弹幕显示在同一个列表中，带平台标记和使用各网站自家图标的会员徽章（YouTube 频道的会员徽章，B站的舰长/提督/总督图标；猫耳FM 的贵族/超粉显示为 💎）。每个列表都有按网站显示/隐藏的复选框；侧边栏的单一字号设置可同时调整所有列表。弹幕时间默认使用服务器时区，可在侧边栏 **🕒 弹幕时区** 中更改（会以 `?tz=` 记在网址中）。发送框旁的 **特制表情包** 选择器提供 YouTube 频道表情、B站房间表情包和猫耳FM 房间表情及其预设颜文字。YouTube 频道表情从弹幕中收集；登录后显示全部，无法使用的表情带 🔒。B站表情包需要登录，🔒 表情可能需要粉丝勋章等条件；主播的 **充电表情** 不登录也会列出，为主播充电后可用。B站和猫耳FM 选择器仅在监听对应房间时可用；YouTube 表情和猫耳颜文字会先加入留言框，点击“发送”后再发送；点击 B站特制表情包会立即单独发送为一条弹幕。YouTube/B站特制表情只发往各自平台，普通 emoji 仍可在文字弹幕中组合发送；点击猫耳房间表情也会立即发送。表情包会按当前 YouTube 直播 / B站房间缓存，切换直播或房间后重新获取。每个表情包都可以折叠（也可用 **全部展开 / 全部收起**）；主播自己的表情包（⭐：充电表情、房间专属表情和主播自己的装扮表情）排在最前并默认展开。装扮表情以装扮名称命名；若装扮商城显示该装扮属于某位 UP主，还会附上 UP主名字。输入的 YouTube 表情代码（如 `:_wave:`）在 YouTube 上显示为表情，发往 B站/猫耳FM 时会去掉。 |
| 🐱 **猫耳FM 房间表情** | 登录后，猫耳FM 选择器会加载当前房间可用的表情包。展开表情包并点击表情即可立即发送；锁定的表情包不可发送。收到的房间表情会在弹幕和 OBS 浏览器弹幕层中以图片显示（仅允许加载猫耳FM 可信 CDN 图片）。 |
| ✉️ **发送** | 一条消息同时发到多个网站（勾选 YouTube / Bilibili / 猫耳FM）。 |
| 🎁 **礼物和醒目留言** | 礼物（包括免费礼物）、醒目留言（Super Chat）、Super Sticker、会员和付费提问显示在单独的一栏。已知礼物价格显示在礼物旁，标题会按币种显示收到金额总和，不会换算或混加币种。YouTube 赠送会员会显示赠送者的购买记录（“赠送了 10 个会员”）和每位领取者（“收到了 … 赠送的会员”）。B站 🧧 红包会显示发送者、价格和内容，开奖后显示中奖者。领取者和中奖者会列出但不会朗读。每一条都可以标记为 🙏 *已感谢*（变灰），或点击 *全部标为已感谢*。 |
| 👋 **进场** | 宽屏时，进入直播间的观众显示在礼物下方的单独列表中；窄屏单排时只在弹幕中显示最新进入的一位，不显示其他进场列表和控件。 |
| 🛡️ **管理** | 点击任意消息上的 🚫 即可屏蔽该用户。屏蔽用户、关键词与正则过滤以及白名单保存在 `chat_filters.json` 中，重启后仍然有效。 |
| 🌐 **翻译** | 在侧边栏启动翻译后，弹幕和实时转录中与所选目标语言不同的内容都会翻译成该语言。支持中文（简体/繁体）、英语、日语和韩语。优先使用免费的 Index-Translate，失败时自动回退到 Google。内置直播术语表会覆盖“舰长”“醒目留言”“上舰”“弹幕”等词的机器翻译。 |
| 🎙️ **实时转录** | 每次可转录一个正在监听的 YouTube、Bilibili 或猫耳直播。运行时，最近三条转录会显示在弹幕和礼物两栏上方的全宽吸顶面板中。语音识别使用本地 faster-whisper；所选模型会在首次使用时下载。需要 FFmpeg。启动翻译后，只有识别语言与所选目标语言不同时才翻译转录内容。 |
| 🔤 **注音** | 在醒目留言文字、礼物名和用户名上方显示拼音 / 振假名注音，方便主播念出来；日语译文加振假名，醒目留言和礼物的中文译文加拼音。 |
| 💾 **记住设置** | 你的设置（朗读、翻译、消息顺序、文字大小、OBS 叠加层选项、语言、时区等）保存在当前浏览器中，下次打开时自动恢复。弹幕区布局会根据屏幕宽度自动切换。房间号、直播链接和弹幕不会保存；登录使用单独的 Cookie。 |
| 🔊 **语音朗读** | 在本机朗读弹幕（离线 `pyttsx3` 或在线 gTTS），或 **在观众的浏览器中用设备自带语音朗读**（从其他设备或 Streamlit Cloud 打开仪表板时会自动使用）。包括：语言筛选、跳过表情、朗读翻译后的文字（当朗读语言为自动检测或与 *翻译为* 一致时）、普通弹幕不读用户名、**优先播报礼物和醒目留言**、每条消息上的 🔊 重播按钮，以及可立即打断敏感评论的 **⏭ 跳过 / ⏹ 停止朗读** 按钮。 |
| 📡 **直播监控** | 每个网站的控制项（直播链接 / 房间号、开始/停止监听、登录状态），以及各平台的开播 / 未开播状态、标题和观看人数。 |
| 🎬 **OBS** | 主播专用的 OBS 标签页：连接、开始/停止直播和录制、切换场景和来源（OBS WebSocket v5）、把弹幕发送到 OBS 文本源，以及只显示弹幕的浏览器源叠加层。在该标签页中打开 *连接 OBS* 之前不会生效。 |
| 📊 **数据分析** | 观看人数（从直播监控中采样）、每分钟弹幕数图表、发言最多的用户、按平台统计的礼物和醒目留言数量/收益（保留各平台原始币种），以及用于切片的 🔥 热点（CSV、时间戳列表和 DaVinci Resolve EDL 标记）。 |
| 🍪 **Cookies** | 导入 B站、猫耳FM 和 YouTube 的登录 Cookie：从本机浏览器（Chrome / Edge / Firefox）读取，或粘贴 / 上传从任意浏览器导出的 Cookie（适用于服务器）。 |

## 运行要求

- Python 3.10+（在 3.14 上开发）
- Windows、macOS 或 Linux（离线语音取决于操作系统）
- 可选的实时转录：需安装 FFmpeg 并将其添加到 `PATH`；faster-whisper 和 yt-dlp 会随依赖一起安装。Whisper 模型在首次使用时下载。
- 可选：启用了 WebSocket 服务器的 [OBS Studio](https://obsproject.com/) 28+

## 安装

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## 配置

设置从项目根目录的 `.env` 文件读取（通过 `python-dotenv` 加载）。先复制模板：`Copy-Item env.template .env`（macOS/Linux：`cp env.template .env`）。所有设置都是可选的，只需填写你使用的平台。网站登录 **不** 在 `.env` 中设置：每个人在 🍪 Cookies 标签页导入自己的 Cookie（见 [登录以发送弹幕](#登录以发送弹幕)）。

模板中只有占位值（`your-…`、`xxx`）。**请替换或删除这些行**，占位值会被当成真实设置（例如占位的 `OBS_PASSWORD` 会让程序用它去登录 OBS）。

| 变量 | 用途 | 默认值 |
|---|---|---|
| `YOUTUBE_API_KEY` | YouTube Data API 密钥，可选；没有它（或配额用完）时，读取弹幕和直播状态会改用公开网页 | — |
| `YOUTUBE_CHANNEL` | 直播监控标签页中默认的 YouTube 频道链接（或直播链接）；点击 *开始监听* 即可监视 | `https://www.youtube.com/@Ya-chan` |
| `BILIBILI_ROOM_ID` | 默认 B站直播间 | — |
| `MISSEVAN_ROOM_ID` | 默认猫耳FM 直播间 | `869215180` |
| `INDEX_TRANSLATE_API_BASE` | Index-Translate 兼容 API 地址；留空可禁用并直接使用 Google | `https://index-translate.bilibili.com/v1` |
| `INDEX_TRANSLATE_MODEL` | Index-Translate 模型 | `Index-Translate-35B-A3B` |
| `OBS_HOST` | OBS WebSocket 主机 | `localhost` |
| `OBS_PORT` | OBS WebSocket 端口 | `4455` |
| `OBS_PASSWORD` | OBS WebSocket 密码 | — |
| `OVERLAY_HOST` | 弹幕叠加层监听地址：`127.0.0.1` = 仅本机，`0.0.0.0` = 其他机器也可访问 | `127.0.0.1` |
| `OVERLAY_PORT` | 弹幕叠加层端口 | `8502` |
| `OVERLAY_PUBLIC_URL` | 在 🎬 OBS 标签页中显示的叠加层地址（例如 `http://203.0.113.5:8502` 或反向代理地址） | 自动 |
| `ANALYTICS_ENABLED` | 设为 `false` 可隐藏两个应用中的数据分析页面/标签，并停止收集观众历史、活动和热点数据 | `false` |
| `TTS_USE_GTTS` | `true` = 在线 gTTS，`false` = 离线 pyttsx3 | `false` |
| `TTS_QUEUE_LIMIT` | 离线普通弹幕和进房播报队列上限；满时丢弃最早的等待消息 | `20` |
| `TTS_PRIORITY_QUEUE_LIMIT` | 离线礼物和 Super Chat 优先队列上限；满时丢弃最早的优先消息 | `50` |
| `TTS_TASK_LIMIT` | 桌面版运行中及等待中的语音生成任务总上限；满时跳过新播报 | `20` |
| `TTS_AUDIO_QUEUE_LIMIT` | 桌面版在线音频待播放队列上限；满时丢弃最早的待播放音频 | `20` |
| `CHAT_POLL_INTERVAL` | 弹幕刷新间隔（秒） | `5` |
| `ROOM_STATUS_POLL_INTERVAL` | 桌面版和浏览器版的直播状态、标题及观众数轮询间隔（秒），也用于 YouTube 频道监控。最小为 `1`，修改后需重启。轮询检测到开播时触发通知。 | `60` |
| `CHAT_TRANSLATION_DISPLAY_MODE` | 翻译显示方式：`immediate` 立即显示弹幕，译文就绪后补上；`wait` 等译文就绪后再显示弹幕 | `immediate` |
| `LOGIN_SECRET` | 加密每个用户保存在浏览器中的登录信息的密钥。更改后所有人都会被登出 | 随机生成，保存在 `.login_secret` |

> ⚠️ `.env` 和 `.login_secret` 包含机密信息，已列入 `.gitignore`。切勿提交或分享。
>
> 翻译优先使用 Index-Translate，不可用或返回无效结果时会回退到 Google。在 `.env` 中设置 `INDEX_TRANSLATE_API_BASE=` 可禁用 Index-Translate。启用翻译会把弹幕文本发送给翻译服务。
>
> `CHAT_TRANSLATION_DISPLAY_MODE` 可设为 `immediate` 或 `wait`，修改 `.env` 后重启 Web app 生效。`wait` 模式下，翻译失败或目标语言改变时会显示原文，不会丢弃弹幕。

## 运行

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

然后打开 <http://localhost:8501>。在同一网络的平板上使用时，打开 `http://<电脑IP>:8501`。

如需更精简的监控界面，可运行以下命令。它会自动监听 `.env` 中配置的平台，并显示直播状态、弹幕和礼物：

```powershell
.\.venv\Scripts\python.exe -m streamlit run simple_app.py
```

精简版仍在侧边栏提供翻译和浏览器文字转语音设置。

可在 `.env` 中配置新会话的默认值（参见 `env.template`）：

| 参数 | 默认值 | 用途 |
|------|--------|------|
| `SIMPLE_PAGE_LANGUAGE` | `ja` | 界面和翻译语言：`en`、`zh` 或 `ja` |
| `SIMPLE_TRANSLATION_ENABLED` | `true` | 默认开启弹幕翻译 |
| `SIMPLE_TTS_TRANSLATE` | `true` | 启用 TTS 时朗读翻译后的弹幕 |
| `SIMPLE_NOTIFY_LIVE` | `true` | 默认开启开播通知；仍需浏览器授权 |

修改后请重启。已有会话保留侧边栏中的选择，TTS 本身仍默认关闭。

Windows 完成安装后，可双击 [Start_Simple_Monitor.bat](Start_Simple_Monitor.bat) 启动。

默认端口为 8501，可通过环境变量 `SIMPLE_MONITOR_PORT` 修改。

## 使用方法

### 读取弹幕（无需登录）

有直播间正在监听时，直播监控页顶部会提示切换到顶栏的 **💬 弹幕** 页面观看；全部停止监听后提示自动隐藏。

每个网站在 **📡 直播监控** 标签页中各有一栏，每栏的布局相同：

1. **🔑 登录**：当前登录的账号（每 5 分钟重新检查）、*登录已过期*，或 *未登录 — 弹幕为只读*。
2. **房间号或链接**：要读取的直播。
3. **🎧 监听**：*监听中 ✓* / *连接中…* / *未监听*，以及 **▶ 开始监听** 和 **⏹ 停止监听**。更换房间会停止当前的监听。
4. 直播的开播 / 未开播状态、标题和观看人数。

**房间号或链接** 中填写：

- **YouTube**：直播链接或视频 ID。也可以填 **频道链接**（例如 `https://www.youtube.com/@Ya-chan`）：程序每 60 秒检查一次频道，开播后立即开始读取弹幕，直播结束后回到监视状态。
- **B站**：房间号或链接（例如 `https://live.bilibili.com/21452505`，或 `b23.tv` 分享链接）。没有登录 Cookie 时，B站会隐藏用户名（例如 波***）。
- **猫耳FM**：房间号或链接（例如 `https://fm.missevan.com/live/869215180`）。

### 登录以发送弹幕

1. 在平时使用的浏览器中登录该网站。
2. 在 **🍪 Cookies** 标签页选择浏览器和网站，导入 Cookie 后点击 **✅ 使用这些 Cookie**。
   - **程序运行在服务器 / 另一台电脑上？** 程序只能读取它所在机器上安装的浏览器（否则会出现 `Could not find Firefox profile directory`），所以只有在那台机器上打开仪表板时才会提供 **🧭 本机浏览器**。请改选 **📋 粘贴 / 上传 Cookie**，粘贴从自己的浏览器导出的 Cookie：从开发者工具复制的 `Cookie:` 请求头（F12 → Network），或者 *Get cookies.txt LOCALLY*（Netscape `cookies.txt`）、*Cookie-Editor*（JSON）等扩展导出的内容。也可以直接上传导出的文件。
3. 在消息框上方的 **发送到** 中勾选网站，然后发送。

猫耳FM 发送弹幕使用已导入账号，并要求账号具备该直播间的发言资格（猫耳FM 网页端要求账号已绑定手机号）。若绑定后仍无法发送，请重新导入最新的猫耳FM Cookie。

**登录按用户区分。** 每个打开仪表板的人都有自己的登录：你的 Cookie 不会被其他人使用或看到，其他人也不能以你的身份发送弹幕。你的登录信息只以加密 Cookie 的形式保存在你自己的浏览器中（服务器只保存密钥 `LOGIN_SECRET` / `.login_secret`），因此刷新页面或重启服务器后依然有效。在其他浏览器或无痕窗口中打开仪表板时为未登录状态。你启动的监听会使用启动时的登录。

每个 **📡 直播监控** 栏中的 🔑 行显示登录状态。猫耳FM 的 Cookie 过期后无法发送到猫耳FM。点击下方的 **🚪 清除登录** 可以忘记该网站的 Cookie：它们会从本次会话和本浏览器中删除，弹幕仍可只读。

如果你的 Google 账号拥有多个 YouTube 频道（品牌账号），YouTube 登录行下方会出现 **发送身份** 选择器，选择要用来发送弹幕的频道即可。该选择按用户区分，并随登录一起保存。要使用其他 Google 账号，请在 🍪 Cookies 标签页导入该账号的 Cookie。

用浏览器 Cookie 向 YouTube 发送弹幕属于非官方方式（与 youtube.com 本身的做法相同），只适用于开启了聊天的直播。

### 弹幕显示

弹幕自动跟随最新消息（按所选顺序位于顶部或底部）。手动滚离最新位置时暂停跟随，方便查看历史；回到最新位置或点击箭头按钮即可恢复。

- 在 **全局设定** 侧边栏使用 **弹幕文字大小** 滑块，同时调整弹幕、礼物和进场文字（80–200%）。
- 在侧边栏选择 **最新在上** 或 **最新在下**，统一调整实时转录、弹幕和礼物列表的消息顺序。
- 宽屏时，实时转录和弹幕在左栏，礼物和醒目留言在右栏；窄屏时礼物和醒目留言会移到实时转录与弹幕之间，并可通过标题折叠整个区域。
- 滚动弹幕时，实时转录预览会吸顶显示；普通弹幕保留时间戳，隐藏会员文字标签，弱化用户名并突出弹幕正文。
- 窄屏单排会隐藏独立的进场列表和相关控件，只在弹幕中显示最新进入的一位。
- 列表上方的 YouTube / Bilibili / 猫耳FM 复选框用于显示或隐藏各网站的消息。
- 只有弹幕列表会按 `CHAT_POLL_INTERVAL` 秒自动刷新（默认 5 秒）；轮询不会重新运行其他标签页和上方控件。侧边栏的 *最多显示消息数* 限制屏幕上保留的弹幕条数。
- 侧边栏的 *🗑️ 清空弹幕记录* 会清空弹幕和进场，但保留礼物和醒目留言，以免漏掉还需要感谢的人。

启用翻译后，程序优先使用 Index-Translate，服务不可用或响应无效时会自动回退到 Google。内置直播术语表会覆盖“舰长”“醒目留言”“上舰”“弹幕”等词的机器翻译。将 `.env` 中的 `INDEX_TRANSLATE_API_BASE` 设为空可关闭 Index-Translate、直接使用 Google。启用翻译会把弹幕文本发送给翻译服务。

### 礼物和醒目留言

- 新的礼物和醒目留言出现在右侧一栏。感谢观众后点击该条目，它会变灰并显示 ✅ *已感谢* 标记。再次点击可撤销。
- *🙏 全部标为已感谢* 会标记当前所有未感谢的条目。
- 每条有价格数据的礼物旁会显示价格；区域标题显示收到总额，并按币种分开累计。
- 感谢状态只在当前浏览器会话中保留。

### 翻译

弹幕原文先显示，不等待翻译请求；译文准备好后在后续刷新中补上。译文朗读也延后排队，不阻塞新弹幕；静音列表或停止朗读会取消相应的待朗读内容。

实验性实时转录默认隐藏。在 `.env` 中设置 `TRANSCRIPTION_ENABLED=true` 并重启仪表板，即可显示转录入口和实时预览；设为 `false` 可再次隐藏。弹幕翻译不受此开关影响。

在侧边栏选择目标语言并开启 **启动翻译**。开启后，弹幕和转录中与目标语言不同的内容都会翻译成该语言。程序优先使用 Index-Translate；服务不可用或结果无效时会回退到 Google。内置直播术语表会覆盖“舰长”“醒目留言”“上舰”“弹幕”等词的机器翻译。若想直接使用 Google，可在 `.env` 中将 `INDEX_TRANSLATE_API_BASE` 设为空。需要翻译的弹幕和转录文本会发送给翻译服务。

### 屏蔽用户

通过顶栏与 Deploy 同排的图标和文字入口切换页面；窄屏可横向滚动入口。首次进入时默认显示直播监控，转录入口仅在启用时显示。设置仍放在默认隐藏的 ☰ 抽屉中，悬浮覆盖页面而不挤压内容，也可按 Escape 关闭。

- 点击消息上的 🚫 即可屏蔽发送者。其消息会从仪表板中消失，之后也会被过滤；不会向 YouTube / B站 / 猫耳FM 发送任何内容。
- 屏蔽按平台区分，保存在 `chat_filters.json`（已被 git 忽略）中，重启后仍然有效。从左侧栏选择 **🛡️ 过滤**，点击 ✕ 取消屏蔽。
- **🛡️ 过滤** 页面还可以手动添加要屏蔽的关键词、正则表达式和用户名 / ID。

### 语音朗读

开启语音朗读后，弹幕顶部直接显示选项，不再需要高级模式。**表情** 跳过表情和贴图，**用户名** 跳过弹幕用户名，**译文** 朗读翻译后的弹幕；按钮开启时高亮，再次点击关闭。

每个列表使用纯喇叭图标按钮切换静音，悬停提示说明操作；表情和用户名按钮开启时显示静音喇叭，关闭时显示有声喇叭。

礼物和醒目留言的翻译朗读选项也标为 **译文**。两个译文按钮开启时为实心绿色，关闭时为绿色边框。

在侧边栏的 **🔊 语音朗读** 中设置：*启用语音朗读*、*语言*、*语速（WPM）* 和 *音量*。用 *▶ 试听* 检查效果。开启语音朗读后，每个列表（礼物和醒目留言、弹幕、进场）顶部都有 **🔊 朗读 / 🔇 不朗读** 按钮，决定是否朗读该列表；弹幕列表顶部还有 *忽略表情包*、*不朗读用户名*（礼物和醒目留言仍会说出发送者）和 *朗读翻译后的弹幕*；礼物和醒目留言列表顶部还有 *朗读翻译后的醒目留言*（礼物名称始终按原样朗读）。默认朗读礼物和醒目留言以及弹幕，不朗读进场。礼物和醒目留言无论语言都会优先朗读；进场每次更新只读最新几条。

要打断敏感评论，请使用 **各列表上方右侧** 的按钮（语音朗读开启时显示）：**⏭ 跳过** 停止当前消息并继续下一条；**⏹ 停止朗读** 停止并清空所有排队的消息。之后到达的新弹幕仍会被朗读，要完全静音请关闭 *启用语音朗读*。

引擎（离线 pyttsx3 或在线 gTTS）由 `.env` 中的 `TTS_USE_GTTS` 选择。

**朗读设备 → 本浏览器（设备语音）** 改用浏览器的 Web Speech API，因此在 Streamlit Cloud 或远程服务器（没有扬声器）上也能使用。远程观看者总是使用浏览器语音。页面必须保持打开，而且浏览器只有在你点击过页面一次之后才允许播放声音。

### OBS

在 OBS 中：**工具 → WebSocket 服务器设置**，启用服务器并设置与 `.env` 中相同的端口/密码。然后打开 **🎬 OBS** 标签页并开启 **连接 OBS**（默认关闭，关闭时仪表板不会连接 OBS）。所有 OBS 功能都在这个标签页中：连接 OBS 后会显示直播/录制控制、场景和来源；如果 OBS 没有运行，会显示未连接，并每 15 秒重新检查一次。

要在 OBS 中显示弹幕，请添加一个 **文本 (GDI+)** 来源（或 FreeType 文本来源），然后在 🎬 OBS 标签页中启用 **将弹幕发送到 OBS 文本源** 并选择它。该来源显示最近 10 条普通弹幕（从旧到新），不含用户名和徽章。启用 **启动翻译** 时，已有的译文会显示在原文下方；关闭后下次更新时会去掉译文。OBS 弹幕输出需要手动开启，并使用已配置的 WebSocket 服务器；单独的浏览器源叠加层预览不会更新这个文本源。

也可以添加一个 OBS **浏览器源**，指向 `http://localhost:8502/overlay`（不是 `:8501/overlay`）。该页面把醒目留言、礼物和会员（B站醒目留言和礼物、猫耳FM 付费提问和礼物、YouTube Super Chat/Super Sticker 和会员）固定在叠加层顶部，普通弹幕在底部，所以弹幕再多也不会把付费消息挤走（默认 3 条；把 **OBS 叠加层显示的醒目留言和礼物数** 设为 0 可隐藏）。普通弹幕显示最近的几条（默认 5 条；在 🎬 OBS 标签页中更改 **OBS 叠加层显示的消息数**，1–50），只有启用 **启动翻译** 时才显示已有的译文，还可以显示自定义叠加层消息。在 🎬 OBS 标签页中关闭 **在 OBS 叠加层显示用户名** 即可只显示弹幕文字（默认开启）；预览也遵循同样的设置。B站自定义表情（例如 `[doge]`）、表情弹幕、YouTube 频道自定义表情（如 `:_wave:` 等会员表情）和 Super Sticker 图片在仪表板、预览和浏览器源中都以图片显示；OBS 文本源只能显示文字代码。仪表板需保持打开才能更新。端口 8502（`OVERLAY_PORT`）必须空闲；如果叠加层服务器无法启动，🎬 OBS 标签页会显示错误。即使 *连接 OBS* 关闭，浏览器源也能使用。叠加层默认只监听 `127.0.0.1`；仪表板运行在服务器上时，请设置 `OVERLAY_HOST=0.0.0.0`（并在防火墙中开放该端口），这样你电脑上的 OBS 才能加载 `http://<服务器>:8502/overlay`，🎬 OBS 标签页会显示准确的网址。叠加层是只读的，只显示公开弹幕。如果多人使用同一个仪表板，请在 🎬 OBS 标签页中给每人设置不同的 **叠加层频道**（会在叠加层网址中加上 `?ch=名称`）；否则所有打开的仪表板都发布到同一个叠加层，以最后一个为准。

要让叠加层只显示部分网站，请在 🎬 OBS 标签页的 **此叠加层显示的网站** 中选择，或自己在网址中加上 `site=`：`/overlay?site=youtube`、`/overlay?site=bilibili,missevan`、`/overlay?ch=alice&site=bili`（也可以用简称 `yt`、`bili`、`me`）。每个网址各自使用完整的消息条数，所以可以每个网站添加一个浏览器源（例如一边放 YouTube 弹幕，另一边放 B站弹幕）。不加 `site=` 时显示所有网站。

要在叠加层（醒目留言、礼物、弹幕及其译文）的汉字上方显示**拼音 / 振假名**，请在 🎬 OBS 标签页的 **OBS 叠加层注音（拼音 / 振假名）** 中选择 *自动*、*拼音* 或 *振假名*。独立链接可加上 `ruby=auto`、`ruby=pinyin` 或 `ruby=furigana`。观众也会看到，而且每行会变高，所以默认关闭。
要把醒目留言和弹幕放在**不同的画面或场景**，请使用 🎬 OBS 标签页顶部的 *仅醒目留言和礼物*（`n=0`）和 *仅弹幕*（`sc=0`）链接，各添加一个浏览器源。某一部分设为 0 时，另一部分会占满整个浏览器源的高度。

**Streamlit Community Cloud / 托管的仪表板：** 这类环境只公开仪表板端口，因此无法访问 `:8502/overlay`。这时 🎬 OBS 标签页会改为显示仪表板链接，例如 `https://your-app.streamlit.app/?view=overlay&youtube=@channel&n=10&sc=5`。该页面只显示叠加层，每 2 秒刷新一次。如果在 OBS 中背景不透明，请在浏览器源的 *自定义 CSS* 中加入 `body, .stApp { background: transparent !important; }`。

## 常见问题

| 问题 | 解决方法 |
|---|---|
| OBS 显示“未连接” | 警告会写明原因。*没有响应*：OBS 没有运行或其 WebSocket 服务器未开启，请启动 OBS / 启用服务器，并检查 `OBS_HOST` / `OBS_PORT`。*拒绝登录*：`OBS_PASSWORD` 错误。不使用 OBS 时请关闭 *连接 OBS*。 |
| 仪表板运行在服务器上时 OBS 无法连接 | `OBS_HOST=localhost` 指的是服务器自己。请把 `OBS_HOST` 设为运行 OBS 的电脑的 IP，确保服务器能访问它（同一局域网、Tailscale 等 VPN 或端口转发），并在该电脑的防火墙中放行 4455 端口。弹幕叠加层（`:8502`）只监听 `127.0.0.1`，除非你设置 `OVERLAY_HOST=0.0.0.0` 并在服务器防火墙中放行该端口。 |
| `bilibili-api-python not installed or connection failed` | 在虚拟环境中运行 `pip install -r requirements.txt`；检查房间号和网络。 |
| YouTube 发送：“Chat is disabled” | 该直播关闭了聊天，或没有在直播。 |
| 离线时有些语言不朗读 | 离线朗读使用 Windows 中安装的语音。请在 *设置 → 时间和语言 → 语音* 中确认有中文 / 日语语音，或设置 `TTS_USE_GTTS=true`。 |
| 离线时没有韩语语音 | 在 Windows 中安装韩语语音（设置 → 时间和语言 → 语音），或设置 `TTS_USE_GTTS=true`。 |
| 语音朗读没有声音 | 检查 *启用语音朗读*、音量，以及消息语言是否与朗读 *语言* 一致（或使用 *自动检测*）。 |
